## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Key.png" width="35" align="center" /> Quick Start

<blockquote>
<p>Get up and running locally in seconds.</p>

1. Ensure you have the <a href="https://shopify.dev/themes/tools/cli">Shopify CLI</a> installed.
2. Authenticate: <code>shopify login --store your-store.myshopify.com</code>
3. Serve locally: <code>shopify theme dev</code>
4. Deploy: <code>shopify theme push</code>
</blockquote>
