### 🛍️ About This Project

Welcome to the **Corso Velle V2** Shopify Theme repository! This project represents a highly customized, sleek, and performant e-commerce storefront designed to deliver a seamless shopping experience. 

Blending **beautiful frontend aesthetics** with robust **Shopify Liquid** architecture, this theme is built to convert visitors into loyal customers while looking incredibly stylish.

- ✨ **Design:** Modern, clean, and highly responsive.
- ⚡ **Performance:** Optimized for fast loading times and smooth interactions.
- 🛠️ **Customization:** Built with modular sections and blocks for easy store management.

### 📂 Theme Architecture

Navigating the codebase like a pro:

| Directory | Purpose |
| :--- | :--- |
| 📁 `assets/` | Where the CSS, JS, and image magic happens. |
| 📁 `blocks/` | Reusable theme blocks for Section Everywhere compatibility. |
| 📁 `config/` | Theme settings schema and current store configurations. |
| 📁 `layout/` | The master wrappers (`theme.liquid`, etc.) holding it all together. |
| 📁 `locales/` | Translation files for a global shopping experience. |
| 📁 `sections/` | Modular, customizable sections powering the storefront UI. |
| 📁 `snippets/` | Reusable snippets of Liquid code to keep things DRY. |
| 📁 `templates/` | JSON and Liquid templates dictating page structures. |

### 🚀 Getting Started

To work on this theme locally using the Shopify CLI:

1. **Install Shopify CLI**: Follow the [official documentation](https://shopify.dev/themes/tools/cli).
2. **Authenticate**: Run `shopify login --store your-store.myshopify.com`
3. **Serve the Theme**: 
   ```bash
   shopify theme dev
   ```
4. **Deploy Changes**:
   ```bash
   shopify theme push
   ```
